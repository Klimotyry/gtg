# Byte Shop Bot Template

Шаблон Telegram-бота для покупки и продажи Byte Coin (BC), собранный по присланным скриншотам.

## Уже реализовано

- Главное меню: Купить / Продать / Информация / Профиль
- Покупка: курс, резерв, быстрые суммы, расчёт количества BC
- Заглушки способов оплаты: СБП, CryptoBot, Telegram Stars
- Продажа: курс, резерв, быстрые суммы, расчёт BC для перевода
- Способы выплаты: СБП, карта, CryptoBot
- Сохранение СБП и карты в локальную SQLite-базу
- Профиль пользователя
- Кнопки поддержки и канала
- Готовые точки для будущего подключения платёжного API и API перевода монет

## Безопасность

Токен бота, `.env` и база данных не должны попадать в GitHub. В `.gitignore` уже исключены:

- `.env`
- `data/`
- `*.db`, `*.sqlite`, `*.sqlite3`

В репозитории находится только `.env.example` с пустым шаблоном.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Windows:

```powershell
.venv\Scripts\activate
copy .env.example .env
```

Откройте `.env` и укажите новый Telegram Bot Token, ссылки поддержки/канала и нужные курсы.

Запуск:

```bash
python -m app.main
```

При первом запуске автоматически создастся `data/bot.db`. Эта папка игнорируется Git и не будет загружаться в репозиторий.
